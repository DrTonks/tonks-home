# 主页截图说明

将截图按下表命名并放在本目录，README 已预留对应图片引用。文件名区分大小写，格式使用真正的 PNG；不要仅修改 JPG / WebP 的扩展名。

| 文件名 | 拍摄内容 | 操作与构图 |
| --- | --- | --- |
| `home-desktop.png` | 亮色主题的完整展开主页，作为主图 | 打开 https://tonks.top/，切换亮色，点击中心头像展开；保留热力图、技术栈、状态、日历、博客与音乐卡片，以及桌宠。已有同名文件可直接替换。 |
| `home-dark.png` | 暗色主题的完整展开主页 | 保持与主图相同的窗口尺寸和展开状态，切换暗色主题，等待背景与卡片过渡结束。 |
| `pet-context-menu.png` | 桌宠右键菜单 | 在展开主页上右键桌宠，保留完整菜单、桌宠和一部分主页背景，突出角色切换、记忆等实际可用入口；不必强行截全页。 |

建议桌面视口约 1440 × 900 或更大，同组截图保持相同比例。等待字体、图表和图片加载完成再拍摄；尽量只截网页内容，去掉浏览器标签栏、侧栏及桌面。使用访客视角，不展示管理员凭据或私人记忆。

这是一份补图清单，不代表所有图片已经就绪。图片放入后即可由 README 显示，无需改代码；后续替换时保持文件名，并在此记录实际拍摄日期。
