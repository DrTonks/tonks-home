三个月保留期从业务数据软删除时间起算；成功写入新留言时懒检查，每天最多清理一次，失败不影响新留言。发布回滚备份独立保留，不属于这项业务数据懒清理。

## 可复跑命令

主页安装依赖后执行 `node node_modules/vue-tsc/bin/vue-tsc.js -b`、`node node_modules/vitest/vitest.mjs run src`。浏览器回归需要Playwright及Edge，可设置 `PLAYWRIGHT_MODULE_PATH` 指向宿主提供的 `playwright/index.mjs`，再执行 `node scripts/test-community-browser.mjs`；若项目安装了Playwright则不必设置该变量。脚本自行启动/关闭本地Vite并关闭浏览器。

后端依赖齐备后执行专用 `python -B -m unittest discover -s tests -p test_community_logging.py -v`。全量测试须使用隔离配置和数据库，方法见后端F6说明，不使用生产数据。
